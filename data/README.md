\# data/



Curated datasets for EdgeTour-RAG.



\- `tourism\_jeju.json` — 729 Jeju tourism entries (attractions, oreums, beaches,

&#x20; museums, viewpoints, temples, parks, plus transport/weather notes). Fields:

&#x20; id, name, name\_ko, category, subcategory, description, latitude, longitude,

&#x20; address, source.

\- `SOURCES.md` — where every entry came from, plus license/attribution notes.



Raw downloads go in `data/raw/` (gitignored). Only curated files are committed.
